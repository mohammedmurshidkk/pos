# Brand: Zentivo POS

Everything that names or draws the product starts in this folder. To rename it
or swap the icon, change these files and run one command. No app code changes.

| File | What it holds |
|---|---|
| `brand.json` | Product name, vendor, colours, installer file name, data folder, ids |
| `icon.svg` | Full app icon (indigo tile + mark), 1024×1024 |
| `mark.svg` | The mark alone, white on transparent, 1024×1024 |

## Rebranding

1. Edit `brand.json`.
2. Replace `icon.svg` and `mark.svg`. Keep the 1024 viewBox, and keep the mark
   white (`#FFFFFF`) on transparent.
3. `pnpm brand` regenerates every icon (list below).
4. Commit the generated files too. CI builds from git and never runs the script.

## Where each value ends up

| Value | Windows (.exe) | Android (APK) | Web / cashier UI |
|---|---|---|---|
| `productName` | installer, Start menu, shortcut, window/tray title, firewall rule | app name under the icon | tab title, sidebar and sign-in footer |
| `colors.primary` | — | adaptive icon background | `theme-color` |
| `colors.splashBackground` | — | splash screen | — |
| `installerFileName` | `ZentivoPOS-Setup-<version>.exe` | — | — |
| `dataFolder` | `%APPDATA%\Zentivo POS` (database, backups, logs) | — | — |
| `ids.appId` / `ids.androidPackage` | Windows app id | Android package | — |

Read by `packages/desktop/electron-builder.cjs`, `packages/desktop/src/main.ts`,
`packages/mobile/app.config.js`, `packages/admin/vite.config.ts`,
`packages/admin/src/brand.ts` and `tools/licence.mjs`.

Generated by `pnpm brand` (`tools/brand.mjs`):

```
packages/desktop/resources/icon.ico   16–256 px: exe, installer, uninstaller, shortcuts
packages/desktop/resources/icon.png   512 px: window icon in dev, macOS
packages/desktop/resources/tray.png   32 px: tray
packages/admin/public/favicon.svg     + favicon-32.png, apple-touch-icon.png
packages/mobile/assets/icon.png       legacy launcher icon
packages/mobile/assets/adaptive-icon.png    mark shrunk into Android's safe zone
packages/mobile/assets/monochrome-icon.png  Android 13 themed icon
packages/mobile/assets/splash-icon.png
```

## Safe to change at any time

`productName`, `shortName`, `vendor`, `description`, `colors`,
`installerFileName`, and both SVGs.

## Change only before the first shop install

- **`ids.appId` / `ids.androidPackage`.** After a change, Windows and Android
  treat the new build as a different program. On Windows it installs beside the
  old one, and both try to use port 4000. On a tablet the new app starts
  unpaired, and the old app's offline queue is left behind.
- **`dataFolder`.** If you rename it, put the old name at the front of
  `legacyDataFolders`. On first start the app moves the old folder across; if
  Windows refuses the move, it uses the old folder where it is. Without this, a
  shop would open to an empty database.

`vendorKeyFolder` is where `tools/licence.mjs` keeps the licence signing key on
the vendor's Mac. A key still in a `legacyVendorKeyFolders` folder is found
there, so nothing needs moving.

The demo restaurant is still **Al Manzil** (`pnpm seed`, tests, docs examples).
That is customer data, not the product brand.
